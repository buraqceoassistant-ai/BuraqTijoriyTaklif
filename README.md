# BuraqTijoriyTaklif

BURAQ Logistics: платформа заявок на груз и согласования КП (UZ / RU / EN).

Сайт: **https://buraqceoassistant-ai.github.io/BuraqTijoriyTaklif/**

## Что в репозитории

- `index.html` — весь сайт в одном файле (React, шрифты и логотип уже внутри).
- `.nojekyll` — отдаёт файлы GitHub Pages как есть, без обработки Jekyll.
- `scripts/build.py` — собирает `index.html` из нового экспорта: добавляет заголовок вкладки, иконку и мета-теги.

## Как включить сайт (один раз)

1. **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. В **Branch** выберите `main`, папку `/ (root)` и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по ссылке выше. Ход сборки виден во вкладке **Actions**
   («pages build and deployment»). Если сборка не запустилась, её запускает любой новый коммит в `main`.

Репозиторий приватный. Для GitHub Pages из приватного репозитория на личном аккаунте нужен
GitHub Pro; на бесплатном тарифе репозиторий нужно сделать публичным.
Сам сайт будет открыт для всех, у кого есть ссылка. Поисковики его не индексируют (`noindex`).

## Как обновить сайт

```bash
python3 scripts/build.py BURAQ_KP_Platforma.html index.html
git add index.html && git commit -m "Обновить сайт" && git push
```

## Ограничения демо-версии

- Вход демонстрационный: подходит любой пароль, данные хранятся только в открытой вкладке.
- AI-функции (AI-помощник, AI-анализ заявки, советы для Sales) работают только внутри Claude.
  На этом сайте вместо ответа они покажут сообщение об ошибке. Остальной интерфейс работает полностью.
- Bitrix24 тоже демо: реальные запросы к порталу не отправляются.
