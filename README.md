# BuraqTijoriyTaklif

BURAQ Logistics: платформа заявок на груз и согласования КП (UZ / RU / EN).

Сайт: **https://buraqceoassistant-ai.github.io/BuraqTijoriyTaklif/**

## Что в репозитории

- `src/app.html` — исходник приложения: разметка экранов, тексты на трёх языках и логика. Правки делаются здесь.
- `index.html` — готовый сайт в одном файле (React, шрифты и логотип внутри). Собирается из `src/app.html`, вручную не правится.
- `scripts/build.py` — упаковывает `src/app.html` в `index.html`.
- `.nojekyll` — отдаёт файлы GitHub Pages как есть, без обработки Jekyll.

## Как включить сайт (один раз)

1. **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. В **Branch** выберите `main`, папку `/ (root)` и нажмите **Save**.
4. Через 1–2 минуты сайт откроется по ссылке выше. Ход сборки виден во вкладке **Actions**
   («pages build and deployment»). Если сборка не запустилась, её запускает любой новый коммит в `main`.

Сайт открыт для всех, у кого есть ссылка. Поисковики его не индексируют (`noindex`).

## Как обновить сайт

1. Измените `src/app.html`.
2. Соберите сайт и отправьте изменения в `main`:

```bash
python3 scripts/build.py
git add src/app.html index.html && git commit -m "Обновить сайт" && git push
```

## Календарь Китая

Раздел «Календарь Китая» есть в меню у всех ролей. Компактный календарь стоит и в форме заявки,
рядом с полем «Дата погрузки». Нажатие на день ставит дату погрузки. Если дата попадает на выходной
КНР или на период пика, под полем появляется предупреждение.

Данные лежат в функции `cnCal()` в `src/app.html`:

- `H` — официальные выходные КНР: даты, рабочие дни-переносы (`work`), периоды пика до (`pre`)
  и после (`post`) праздника, влияние (`imp`: `h` / `m` / `l`).
- `EV` — события: Кантонская ярмарка, распродажи 618 и 11.11, Праздник фонарей.

2026 год — официальный график Госсовета КНР от 4 ноября 2025. 2027 год — предварительный
(`pv:true`), по лунному календарю. Госсовет публикует официальный график в ноябре: после этого
обновите даты 2027 года в `H`, добавьте переносы в `work` и уберите `pv:true`.

## Ограничения демо-версии

- Вход демонстрационный: подходит любой пароль, данные хранятся только в открытой вкладке.
- AI-функции (AI-помощник, AI-анализ заявки, советы для Sales) работают только внутри Claude.
  На этом сайте вместо ответа они покажут сообщение об ошибке. Остальной интерфейс работает полностью.
- Bitrix24 тоже демо: реальные запросы к порталу не отправляются.
